Privacy Policy

Last updated: August 2026

Epoch Buddy is a Solana Mobile application published by Marnik Labs. This policy explains how the application handles user information.

Wallet information

Epoch Buddy can connect to compatible Solana wallets using Solana Mobile Wallet Adapter. Wallet authorization is performed through the user's wallet application. Epoch Buddy does not request or store private keys or seed phrases.

Local storage

The application may store application preferences and wallet session information locally on the user's device using secure application storage.

Notifications

Users may optionally enable epoch-related notifications. Notification permissions are used only to provide functionality requested by the user.

Network access

Epoch Buddy uses network access to retrieve information required for its Solana-related functionality.

External storage

Epoch Buddy does not request access to the user's external storage, photos, videos or other personal files.

Contact

For privacy questions or support, please use the support information provided on the Epoch Buddy website.
